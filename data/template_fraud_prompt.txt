2. ERP/ACCOUNTING SYSTEM SIGNALS (these are POSITIVE authenticity signs, NOT fraud):
   - Structured header with company name, address, tax registration
   - Systematic invoice numbering (e.g., INV/2025/00000, SO-12345)
   - Professional but uniform table layout with columns (Description, Qty, Unit Price, Tax, Amount)
   - Consistent font usage throughout (even if proportional — ERP systems use proportional fonts)
   - Footer with payment terms, bank details, or legal text
   - Multiple date fields (Invoice Date, Due Date, Delivery Date) — typical of ERP systems
   - Source/Reference codes — system-generated identifiers
   - Company logo at a standard position (top-left or top-right)
   - QR CODE placeholder or actual QR code for ZATCA compliance

3. PAPER TYPE & FORMAT
   - POS: narrow roll, cream/grey thermal paper, no page borders
   - ERP Invoice: A4 white paper — this is NORMAL for invoices, NOT a fraud signal by itself
   - Forged: A4 with amateurish layout, inconsistent margins, or obviously hand-designed structure

4. FONT CHARACTERISTICS
   - POS: fixed-width monospaced
   - ERP: proportional system fonts (this is NORMAL for A4 invoices)
   - Forged: random mix of decorative fonts, inconsistent sizes/weights that don't look system-generated, handwriting-style fonts

5. PRINT TECHNOLOGY
   - Thermal: grey/cream tone, no separate ink dots
   - Laser/inkjet (normal for ERP invoices): sharp black on white — NOT a fraud signal for A4 invoices
   - Forged: unusually low-resolution printing, misaligned text, visible copy artifacts

6. QR CODE
   - Saudi ZATCA-compliant documents MUST include an actual rendered QR code image (not just the text "QR CODE")
   - A "QR CODE" text placeholder where the actual QR image should be is a STRONG fraud indicator (score +25) — it means the document was created in a tool that couldn't generate a real ZATCA QR, or the fraudster typed "QR CODE" as placeholder text
   - Complete absence of any QR code or QR reference on a Saudi business document with a tax number is a strong fraud signal (score +20)
   - Only an actual scannable QR code image counts as having a QR code — set has_qr_code to true ONLY if a real QR code image is visible

7. DESIGN COHERENCE
   - Authentic (POS or ERP): all elements consistent, generated by a single system
   - Forged: mismatched element styles, manually positioned text blocks, inconsistent spacing that suggests copy-paste assembly

8. SCREENSHOT / DIGITAL RENDER DETECTION (CRITICAL — score 80-100 if detected):

A dark background (black, dark grey, navy, dark green, etc.) is an ABSOLUTE fraud signal — no printer in the world prints on dark paper for receipts/invoices. This means the image is a screenshot of a web page, app, or digitally designed document.

9. FORGERY-SPECIFIC RED FLAGS (what indicates a Word/Excel/web fake):
