CRITICAL OUTPUT REQUIREMENTS
1. Return ONLY a valid JSON object with no markdown formatting, code fences, or explanatory text.

FIELD EXTRACTION RULES

MerchantName_Keyword (Array):
- Capture ALL distinct merchant name variations visible on the receipt to ensure future matching accuracy.
- Include both Arabic and English versions if both are printed.
- Include brand names, business names, and store names as they appear.
- For English names with curly quotes ('), include both the original and straight-quote version.
- Include any abbreviations or alternative spellings if printed.
- Order: Primary English name, Primary Arabic name, then all variations.
- Return [] if no merchant name is visible.

MerchantAddress_Keyword (Array):
- Include complete address components exactly as printed (Arabic and/or English).
- Include branch identifiers, area names, city names, and district names only if explicitly visible.
- Include both language versions if both are printed.
- Do not generalize location information not explicitly shown.
- Return [] if no address information is visible.

Category and Sub-category:
- Infer from merchant name, items, or visual context if not explicitly printed.
- Category options: "F&B", "Retail", "Entertainment", "Services"
- Sub-category examples:
  • F&B: "Beverages", "Coffee Shop", "Restaurant", "Bakery", "Desserts"
  • Retail: "Perfumes", "Supermarket", "Fashion", "Electronics", "Pharmacy"
  • Entertainment: "Arcade", "Cinema", "Theme Park"
  • Services: "Salon", "Laundry", "Transport", "Telecom"
- Return null if unable to determine.

Spending Range (SAR):
- Derive from the total amount using these ranges: "0-10", "5-50", "50-100", "100-500", "500+"
- Return null if total is not visible or unreadable.

Language:
- Return "Arabic" if only Arabic text is present.
- Return "English" if only English text is present.
- Return "Arabic/English" if both languages are present.
- Return null if unable to determine.

EXTRACTION HINTS RULES

Label Fields (Total_Label, Subtotal_Label, Tax_Label):
- Extract the exact label text as printed on the receipt (e.g., "الإجمالي", "Total", "VAT 15%").
- Return null if not visible.

Value Fields (TaxID_Label, Date_Label, Time_Label, InvoiceId_Label, StoreID_Label, CR_Label):
- Extract only the value, not the label prefix.
- TaxID_Label: Numeric or alphanumeric tax registration number only.
- Date_Label: Date value as printed (e.g., "2025/07/09").
- Time_Label: Time value as printed (e.g., "06:47:29").

- Return null if not visible.

Format Fields (Date_Format, Time_Format):

- Return null if date or time not visible.
